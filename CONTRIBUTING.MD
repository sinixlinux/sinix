We welcome and love contributions and contributors.

Contributing to our Sinix Linux project is easy, **you can do that 3 ways:**

## 1: Getting a copy of sinix

You can install Sinix Linux on a separate drive or dual-boot in your computer, and then you can do changes you would like to suggest.

## 2: Fork this repository and do a PR

> [!Note]
> PR = Pull Request

Like [Manas](https://github.com/ManasManushya-Jawale/), they forked this repository, changed the README, and did a *PR*, suggesting
that i add the current description for Firefox users (i'm using a custom animated banner, but Firefox doesn't support this).

## 3: Issues

You can discuss and tell us things, such as a bug or suggestion, so we can read it and we chose if it's good for Sinix or not. 

## 4: Discord or TikTok

#### tiktok
If you follow or know [my](https://tiktok.com/@tspilloww] TikTok, you can comment in one of my videos giving your opinion, questions,
troubleshooting, suggestions etc.

#### discord
Our Discord server can be found on the links of the README, and you can suggest new things in our dedicated channels.

----------------------------------------------------------------------------------

## i am a contributor and i can't contribute!

You probably don't have permission yet. Send us a message on our platforms (TikTok, Discord etc.) and we will address this problem.

If you want to solve this problem right here on github, send us a issue saying:

* i am a contributor
* where i contributed
